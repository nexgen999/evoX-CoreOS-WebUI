# ⚙️ Configuration

## Structure

`config.json` est découpé en sections numérotées : dépôt, chemins, navigation, réseaux sociaux, header, Home, sources, Download, Store, Services, Documentation, About, Remerciements et Footer.

## 🗂️ Sources

Pour une source complète, mettez toujours l'URL :

```json
"url": "https://example.com/data.json"
```

Cela évite les ambiguïtés lorsque la WebUI et les données vivent dans deux dépôts différents.

## 🎨 Personnalisation

Les SVG de `web/assets/` peuvent être remplacés sans modifier le JavaScript.
