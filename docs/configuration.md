# Configuration

Le fichier principal est `web/data/config.json`.

Pour apprendre toutes les options, consultez `web/data/config.example.jsonc` : il est volontairement très commenté.

Les grandes sections sont :

1. configuration générale ;
2. dépôt GitHub et source des données ;
3. chemins ;
4. navigation ;
5. profil ;
6. réseaux sociaux ;
7. header et téléchargements rapides ;
8. Home ;
9. News RSS/Atom/OPML ;
10. Download et Other Downloads ;
11. Store JSON ;
12. Services et onglets ;
13. Documentation ;
14. About et Remerciements ;
15. Footer et badges ;
16. couleurs et options avancées.
