# 📘 Documentation evoX Core OS WebUI

Bienvenue dans la documentation complète de démonstration. Cette page montre la structure de la Wiki intégrée.

## ✨ Objectif

Cette WebUI fournit une interface sombre, orientée dashboard, pour présenter un dépôt Core OS avec Store JSON, flux RSS/Atom/OPML, téléchargements, services PS5 et documentation Markdown.

### 🧭 Navigation

Utilisez la barre latérale de la documentation pour parcourir les chapitres. L'ordre est contrôlé par `docs.order`.

> 💡 La documentation est indépendante de la navigation principale.
