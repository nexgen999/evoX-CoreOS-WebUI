# 🚀 Démarrage

Placez `index.html` à la racine et `web/` sous le dépôt. Activez GitHub Pages. Modifiez ensuite `web/data/config.json`. Aucune compilation Node n'est nécessaire.

## Deux dépôts

La WebUI peut rester dans `nexgen999/evoX-CoreOS-WebUI` et lire `nexgen999/evoX-CoreOS`, ou être fusionnée dans un fork CoreOS grâce à `github.dataRepository`.
