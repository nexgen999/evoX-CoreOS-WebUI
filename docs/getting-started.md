# 🚀 Démarrage

## 1. Déployer

Placez `index.html` et le dossier `web/` à la racine du dépôt WebUI. Activez GitHub Pages.

## 2. Configurer

Ouvrez `web/data/config.json`. Les commentaires expliquent chaque groupe.

## 3. Vérifier

La Home doit charger le profil GitHub, le Store et les flux configurés.

### 🧪 Dépannage

- Vérifiez les URLs complètes.
- Vérifiez que les sources autorisent CORS.
- Ouvrez la console du navigateur si un flux externe refuse la requête.
