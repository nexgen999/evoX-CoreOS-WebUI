# Démarrage rapide

## Deux dépôts

Le projet recommandé utilise :

- **evoX-CoreOS** : données, JSON, RSS, OPML, archives et documentation.
- **evoX-CoreOS-WebUI** : interface graphique.

La configuration peut cependant pointer vers n'importe quel dépôt ou domaine.

## URL source

La valeur `sourceSite.baseUrl` permet d'indiquer l'origine complète des ressources. Les chemins commençant par `/` sont alors résolus à partir de cette racine.
