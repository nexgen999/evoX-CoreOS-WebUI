# Démarrage

> **evoX Core OS WebUI** — documentation officielle.

Cette documentation décrit le fonctionnement réel du portail, sa configuration et les conventions à respecter pour le déployer sur GitHub Pages.

## Prérequis

- un dépôt GitHub public pour une utilisation sans authentification ;
- GitHub Pages activé ;
- un navigateur moderne avec ES modules, Fetch, DOMParser et localStorage.

## Premier démarrage

1. Placez `index.html` à la racine.
2. Placez le dossier `web` à la racine.
3. Modifiez uniquement `web/data/config.json`.
4. Vérifiez les URLs du dépôt CoreOS.
5. Poussez les fichiers sur GitHub.

## Ne pas faire

Ne déplacez pas `web/css`, `web/js`, `web/data` ou `web/assets` sans modifier les chemins correspondants.
