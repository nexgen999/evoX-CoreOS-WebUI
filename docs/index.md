# evoX-CoreOS Documentation

Bienvenue sur la documentation officielle du projet **evoX-CoreOS**.

## Démarrage Rapide
1. Configurez votre adresse IP PS5 dans l'onglet **PS5 WebUI**.
2. Parcourez le **Store JSON** pour installer ou télécharger directement vos paquets.
3. Téléchargez les archives globales depuis l'onglet **Packs AIO**.

## Intégration
Pour fusionner cette interface dans un dépôt unifié :
Copiez simplement les répertoires `web/` et `index.html` à la racine de votre projet.
