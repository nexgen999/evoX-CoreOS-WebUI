# 🎨 Personnalisation

## Logo

Remplacez `web/assets/logo.svg` ou modifiez `branding.logo`.

## Backgrounds

Les backgrounds sont séparés :

```text
hero-bg.svg
welcome-bg.svg
news-bg.svg
services-bg.svg
thanks-bg.svg
about-bg.svg
sidebar-bg.svg
```

## Icônes

`web/js/icons.js` contient les icônes natives.

Une entrée peut utiliser `iconType: "image"` pour une image personnalisée.

## Navigation

Ajoutez ou retirez des objets de `navigation`.

## Footer

Ajoutez des badges dans `footer.badges`.

## Services

Ajoutez des onglets dans `services.tabs` sans modifier le moteur.

## Textes

Les textes de Home, About, Remerciements, Header et Sidebar sont configurables.
