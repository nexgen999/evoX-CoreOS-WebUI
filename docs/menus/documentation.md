# 📚 Documentation

Cette page est un mini-Wiki.

## Découverte

Le moteur interroge l'arbre récursif GitHub du dépôt configuré.

Il détecte :

```text
docs/*.md
docs/**/*.md
```

## Navigation

Une Sidebar interne liste les documents.

Cette navigation est indépendante de la Sidebar générale.

## Ordre

`docs.order` permet de fixer l'ordre des documents.

Les documents non listés restent disponibles.

## Rendu

Le renderer prend en charge les titres, listes, citations, liens HTTPS, code inline, blocs de code, gras et italique.
