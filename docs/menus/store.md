# 🛒 Store

Le Store lit les JSON du Core OS. Les structures `payloads`, `packages`, `files` et `apps` sont supportées.

### 🔎 Recherche

La recherche porte sur le nom, fichier, description, auteur, catégorie et sous-catégorie.

### 🧱 Vues

La vue Liste est idéale pour un grand catalogue. La vue Tuiles donne une présentation plus visuelle.
