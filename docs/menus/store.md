# 🛒 Store

## Sources

Le Store charge toutes les sources activées dans `store.sources`.

## Normalisation

Peu importe que le tableau s'appelle `payloads`, `packages`, `files` ou `apps` : le moteur convertit chaque objet vers le modèle commun.

## Recherche

Elle est effectuée côté navigateur après chargement.

## Catégories

Elles sont calculées automatiquement.

## Vue liste

La vue liste est idéale pour les catalogues importants.

## Vue tuiles

La vue tuiles met l'icône et la présentation au premier plan.

## Icônes

Une icône native peut être utilisée par son identifiant. Une URL d'image permet d'utiliser un PNG/SVG/ICO.
