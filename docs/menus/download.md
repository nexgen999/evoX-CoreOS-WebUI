# 📥 Download

## AIO

Les cinq entrées prédéfinies utilisent le tag `latest` du dépôt Core OS.

## Other Downloads

Utilisez `otherDownloads` pour ajouter des packs ou des ressources.

### URL à copier

Définissez :

```json
"copyOnly": true
```

La WebUI affiche alors un champ avec le bouton **Copier**.

Les catalogues Pegasus sont préconfigurés de cette manière.

## Ajouter un pack

Ajoutez simplement un objet avec `name`, `description`, `url`, `icon` et `enabled`.
