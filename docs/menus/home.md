# 🏠 Home

La Home est le tableau de bord principal.

## Hero

`home.hero` définit le logo, titre, description, boutons et background.

Les liens `#store`, `#news`, etc. naviguent dans l'application.

## News

Le bloc Dernières News utilise `homeNews`, pas `news`.

`maxItems` limite le nombre d'articles affichés.

## Store

Les catégories sont calculées à partir des données réellement chargées.

## Welcome

`home.welcome` est un encart éditorial avec son propre background.

## Ressources rapides

Les téléchargements configurés dans le Header peuvent être réutilisés dans la Home.

## Merci et statistiques

Le bandeau Merci et la ligne de statistiques restent sous la zone principale afin de conserver la composition du dashboard.
