# Home

> **evoX Core OS WebUI** — documentation officielle.

Cette documentation décrit le fonctionnement réel du portail, sa configuration et les conventions à respecter pour le déployer sur GitHub Pages.

## Présentation

Cette page documente le menu **Home** tel qu'il est exposé dans la WebUI. Elle est chargée dynamiquement depuis le dossier `docs/menus/` et peut donc servir de base réelle à la documentation publique du projet.

## Configuration

La configuration associée se trouve dans `web/data/config.json`. Les paramètres sont regroupés par fonctionnalité afin de limiter les modifications de code.

## Utilisation

Utilisez la navigation de la page pour revenir aux autres sections. Les liens externes s'ouvrent dans un nouvel onglet lorsque cela est approprié.

## Maintenance

Lorsqu'une fonctionnalité est ajoutée, documentez son objectif, sa configuration, ses entrées, son comportement attendu et les erreurs possibles. Cette règle permet de conserver une documentation exploitable par un autre utilisateur du dépôt.
